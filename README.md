QA Analysis – Mobile App Testing (Urban Lunch)

This repository contains the Quality Assurance testing performed during Sprint 5 of a QA training program. The project focuses on testing the Urban Lunch mobile application, validating its functionality, usability, and stability through a structured testing checklist.
The main objective of this project is to verify that the mobile application behaves according to the expected requirements by executing predefined test scenarios and documenting the results.

Project Objectives

Validate the core functionality of the Urban Lunch mobile application
Identify defects and unexpected behaviors
Execute structured test scenarios using a testing checklist
Document test results clearly and systematically
Report detected issues using a bug tracking system

Scope of Testing

The testing process focuses on verifying key user flows within the mobile application, including:
Navigation between screens
User interactions with interface elements

Functional validation of core features
Verification of expected system behavior
Identification of UI and functional issues
Each test scenario was executed and marked according to the observed results.

Test Process

The QA workflow for this project included:
Reviewing the application features and expected behavior
Executing test scenarios from the testing checklist
Recording test results (pass/fail)
Identifying defects during test execution
Creating detailed bug reports in the issue tracking system

Tools Used
